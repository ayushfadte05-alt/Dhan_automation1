This file contains instructions for AI agents working on this project.

## Project Structure

The project is divided into the following directories:

- `backend`: Contains the Python code for the trading agent.
- `frontend`: Contains the React/Vue code for the user interface.
- `docs`: Contains the documentation for the project.

## Development Guidelines

- All new features must be accompanied by unit tests.
- All code must be formatted using Black.
- All code must be linted using Flake8.
- All dependencies must be managed using Poetry.
